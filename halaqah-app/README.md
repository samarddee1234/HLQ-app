# สายใยสามารถดี — ระบบฮาลาเกาะฮฺ (โรงเรียนสามารถดีวิทยา)

เว็บแอปโทนน้ำเงิน–ฟ้า–ขาว ใช้งานบนมือถือเป็นหลัก

## ฟีเจอร์

**นักเรียน**
- หน้าแรก: สเตรคละหมาด, คะแนนสัปดาห์นี้, หัวข้อฮาลาเกาะฮฺ, สถานะการเข้าฮาลาเกาะฮฺ, อัปเดตจากกลุ่ม, เบอร์/Facebook ครู
- สถิติ: กราฟคะแนนรายสัปดาห์, เทียบกับค่าเฉลี่ยกลุ่ม (ไม่เห็นรายบุคคลของเพื่อน), สัดส่วนทัน/สาย/ไม่ขึ้น, การเข้าฮาลาเกาะฮฺ
- อิบาดะฮฺ: เช็คลิสต์ประจำวัน (ติ๊กเอง) + กราฟ 7 วัน
- ฮาลาเกาะฮฺ: หัวข้อ/สรุป/ประกาศรายสัปดาห์, ปฏิทินกิจกรรมทั้งภาคเรียน, "ฮาลาเกาะฮฺคืออะไร" (สรุปจากป้ายของโรงเรียน)
- เครื่องมือ: เวลาละหมาด, ปฏิทินฮิจเราะฮฺ, ลิงก์อัซการ/อัลกุรอาน/ดุอา, ตัวนับซิกรุลลอฮฺ
- ระบายใจ: ส่งข้อความไม่ระบุตัวตน (ไม่เก็บ user id และกลุ่ม)

**มูร๊อบบีย์** (เห็นและแก้ได้เฉพาะกลุ่มตัวเอง — บังคับที่ฐานข้อมูล ไม่ใช่แค่หน้าจอ)
- เช็คละหมาดซุฮรี–อัสรี (ทัน/สาย/ไม่ขึ้น/ลากิจ-ป่วย/รอบเดือนเฉพาะนักเรียนหญิง)
- เช็คการเข้าฮาลาเกาะฮฺรายสัปดาห์
- ภาพรวมกลุ่ม, คะแนนรายคน + กราฟรายคน, เขียนสรุปสัปดาห์, โพสต์ประกาศ, ใส่เบอร์/Facebook
- ใช้เครื่องมือและหน้า "ฮาลาเกาะฮฺ" ได้เหมือนนักเรียน

**แอดมิน**: อนุมัติครู/ย้ายกลุ่ม, จัดการกลุ่ม, แก้หัวข้อรายสัปดาห์ (เริ่มภาคเรียนใหม่), จัดการลิงก์, ตั้งพิกัดเวลาละหมาด, อ่านข้อความนิรนาม

คะแนนละหมาด: ทัน 1 · สาย 0.5 · ไม่ขึ้น 0 · ลากิจ/ป่วย 1 · รอบเดือน 1 (ต่อวักตู) — กราฟแสดงเป็น % ของวักตูที่ครูเช็คแล้ว

## 1) ตั้งค่า Supabase
1. สร้างโปรเจกต์ที่ https://supabase.com (Region: Singapore)
2. **SQL Editor** → New query → วางไฟล์ `supabase/schema.sql` ทั้งไฟล์ → Run
3. New query อีกอัน → วางไฟล์ `supabase/migration_02.sql` ทั้งไฟล์ → Run (รันซ้ำได้ ไม่ทำให้ข้อมูลหาย)
   - ไฟล์นี้ใส่ปฏิทินกิจกรรมภาคเรียน 2/2569 ทั้ง 20 สัปดาห์ให้แล้ว (คัดจากรูปที่ถ่าย โปรดตรวจอีกครั้ง)
4. **Project Settings → API** คัดลอก `Project URL` และ `anon public key`
5. **Authentication → Providers → Email** ช่วงทดลองปิด "Confirm email" ได้ (ตอนใช้จริงควรเปิด)

## 2) รันบนเครื่อง
```bash
cp .env.example .env     # ใส่ URL และ anon key
npm install
npm run dev
```

## 3) ตั้งแอดมินคนแรก
สมัครบัญชีในแอปและลงทะเบียนก่อน แล้วรันใน SQL Editor:
```sql
update public.profiles set role = 'admin' where email = 'อีเมลของคุณ';
```
จากนั้นทำงานต่อในแอปที่แท็บ **แอดมิน** ได้เลย (ไม่ต้องใช้ SQL อีก):
1. **ตั้งค่า** → เลือกจังหวัด/ใส่พิกัดโรงเรียนสำหรับเวลาละหมาด
2. **กลุ่ม** → เพิ่มกลุ่มของแต่ละมูร๊อบบีย์ (ระบุเพศ/ช่วงชั้นถ้าต้องการให้นักเรียนเห็นเฉพาะกลุ่มที่ตรงกัน)
3. **ผู้ใช้** → "รออนุมัติเป็นครู" → ตั้งบทบาทเป็นมูร๊อบบีย์ + เลือกกลุ่ม
4. **ลิงก์** → เพิ่มลิงก์อัซการ/ดุอาที่ผู้รู้ของโรงเรียนอนุมัติ

## 4) เผยแพร่ (Vercel)
อัปโหลดโค้ดขึ้น GitHub (อย่าอัปโหลด `.env`) → Import ที่ vercel.com → ใส่ `VITE_SUPABASE_URL` และ `VITE_SUPABASE_ANON_KEY` → Deploy
ทุกครั้งที่ push โค้ดใหม่ Vercel จะอัปเดตให้อัตโนมัติ

## ข้อควรรู้
- **ความเป็นส่วนตัว:** ตั้งชื่อกลุ่มเป็นชื่อครูหรือรหัสกลุ่ม ไม่ใช้ชื่อระดับ (ใกล้ชิด/ใส่ใจ ฯลฯ) นักเรียนจึงไม่ถูกตีตรา แอปนี้ไม่ได้เก็บระดับกลุ่มของนักเรียน
- **ข้อความนิรนาม:** ให้มอบหมายครูแนะแนวหรือผู้ดูแลอ่านทุกวัน และกำหนดแนวทางรับมือเมื่อพบข้อความที่น่าห่วง
- **เวลาละหมาด/ฮิจเราะฮฺ:** เป็นการคำนวณโดยประมาณ ให้เทียบกับตารางของโรงเรียน/คณะกรรมการอิสลามประจำจังหวัด
- **เนื้อหาศาสนา:** หน้า "ฮาลาเกาะฮฺคืออะไร" สรุปจากป้ายของโรงเรียน ควรให้ฝ่ายตัรบียะฮฺตรวจถ้อยคำก่อนเปิดใช้
- ห้ามใส่ `service_role key` ในแอป และอย่าปิด RLS
